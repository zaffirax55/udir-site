Security architecture

Protection from boot to credential verification.

  • On-device cryptographic verification
  • Secure Boot
  • Signed firmware updates
  • Protected cryptographic key storage
  • Local trust store
  • Certificate chain validation
  • Credential integrity verification
  • Session binding and replay protection
  • Configurable attribute disclosure
  • Secure device configuration
  • Diagnostic event logging
  • No mandatory cloud-based verification
