What is UDIR

Digital identity verification for physical devices

Businesses and public institutions need reliable ways to verify digital credentials in physical environments. UDIR connects to a user's smartphone, receives authorised credentials, verifies their authenticity and hands the result to the connected system.

Key capabilities

  • EUDI Wallet and Mobile ID verification
  • Mobile Driving Licence (mDL) support
  • Privacy-preserving age verification
  • NFC, BLE and QR connectivity
  • Local cryptographic verification
  • Offline operation
  • Windows, Linux and Android integration
  • USB-C interface
  • IP66 protection target
  • Optional battery-powered operation

MODE AEmbedded Verification

All credential processing and cryptographic verification happen inside the device. The host receives verified results and attributes over a documented USB interface. No external verification server or proprietary host SDK is required.

MODE BHost Verification

UDIR acts as a communication interface between the wallet and the host. Verification is performed by the customer's application using the UDIR SDK. Both modes are planned for the same hardware.

Why UDIR

Built for security, privacy and integration

01

Local-First Verification

UDIR is designed to perform cryptographic credential verification directly on the device. For supported use cases, identity documents do not need to be transmitted to external verification servers.

02

Privacy by Design

Only the attributes required for a specific verification process need to be disclosed. Where supported by the credential format, UDIR enables selective disclosure and age-threshold verification without exposing unnecessary personal information.

03

Offline Capable

UDIR supports local credential verification without a continuous internet connection. Locally stored trust information allows supported verification operations to continue in disconnected environments, subject to credential status and trust-data freshness requirements.

04

Universal Integration

UDIR is designed for integration with Windows, Linux and Android systems through a standard USB connection. A documented device protocol and optional SDK provide flexibility for different integration environments.

05

Multi-Standard Architecture

A single hardware platform is designed to support multiple digital identity standards and credential formats. Additional supported formats may be introduced through software updates.

06

OEM-Ready Design

Compact construction, standard interfaces and configurable software make UDIR suitable for integration into existing and newly developed equipment.

How it works

Verification in three steps

Step 1

Connect

The user presents a smartphone with a supported wallet. UDIR opens a session over NFC, Bluetooth Low Energy or QR, and the wallet receives a request for the required attributes.

Step 2

Verify

After the user authorises, the wallet sends credential data and cryptographic proofs. UDIR checks them locally, with no cloud round trip:

  • Credential authenticity
  • Issuer signatures
  • Data integrity
  • Certificate trust chains
  • Credential validity
  • Session binding
  • Device binding, where required
  • Credential status, where supported
Step 3

Integrate

UDIR returns the result to the host system, for example:

  • Age threshold confirmed
  • Identity credential verified
  • Driving licence verified
  • Driving category confirmed
  • Professional attribute verified

The host then decides: authorise a transaction, issue a key or grant access.

Integration & SDK

Flexible integration. One hardware platform.

Two independent approaches: process credentials on the device, or in your application.

MODE A

Embedded Verification

The device performs credential processing and cryptographic verification internally. The host talks to UDIR through a documented USB command protocol. No external verification engine or mandatory SDK is required.

Best for simple integration and minimal personal data on the host.

MODE B

Host Verification

UDIR provides NFC, BLE and QR communication while software on the host processes credentials. The planned SDK gives access to device communication and supported verification functions.

Best for full control of verification logic inside your application.

FAQ

Answers before you decide

What is UDIR?

UDIR is a universal digital identity reader designed to verify electronic identity credentials, mobile driving licences and personal attributes using NFC, BLE and QR communication.

Does UDIR require an internet connection?

UDIR is designed to support offline verification for compatible credential types and scenarios. Periodic connectivity may be required to update trust information or verify credential status.

Does UDIR require a cloud service?

No mandatory cloud service is planned for local credential verification.

Can UDIR verify credentials without an external SDK?

Yes. In Embedded Verification Mode, the device is designed to perform cryptographic verification internally and provide results through a documented USB protocol.

Which operating systems will be supported?

Windows, Linux and Android are planned integration platforms.

Can UDIR be integrated into existing equipment?

Yes. OEM integration is a primary design objective.

Does UDIR support age verification?

Age verification is a planned capability, including privacy-preserving age-threshold verification where supported by the credential.

Can UDIR be used outdoors?

The enclosure is being designed with an IP66 protection target. Final environmental performance will require validation.

Will a portable version be available?

A battery-powered UDIR Mobile configuration is under consideration.

Is UDIR already available for purchase?

Not yet. UDIR is currently in the concept and market validation stage.

Is UDIR EUDI-certified?

No certification is currently claimed. Applicable regulatory, interoperability and conformity requirements will be assessed during product development.
