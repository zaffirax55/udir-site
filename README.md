# UDIR – Universal Digital Identity Reader

Product website (concept stage). Static, no build step:

- `index.html` – main page, self-contained
- `specifications.html` – technical specifications (linked from the footer and the hero button)
- `ind-*.webp` – photos for the industry scenarios in the Applications section (WebP, 960 px)

- Hosting: GitHub Pages (branch `main`, folder `/ (root)`)
- Three.js r128 is loaded from cdnjs; fonts from Google Fonts
- The contact form is a preview only and is not connected to a mail service yet
